# QFAM-QUIC-implementation-Over-Picoquic and Google QUICHE
Implementation of defense mechanism by introducing the concept of crypto challenges into the handshake protocol, experimented over Picoquic and Google QUICHE. The code involve both implementation of Handshake flooding attack, and defense with QFAM techniques.

Note::: This research work is currently confidential and under active development. The complete source code, including the implementation of the QFAM defense mechanism over Picoquic and Google QUICHE, will be made publicly available after the associated research paper has been submitted.
